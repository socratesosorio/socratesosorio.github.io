Part 2.1: Image "Sharpening"

I implemented the unsharp masking technique to enhance image sharpness by emphasizing high-frequency details.

Unsharp Masking Theory

The unsharp masking technique works by:

  1. Creating a blurred (low-pass) version of the image
  2. Subtracting the blurred version from the original to extract high frequencies
  3. Adding scaled high frequencies back to the original image
# Unsharp masking formula: sharpened = original + α · (original - blurred) # where α controls the sharpening strength

Alpha Value Analysis:

  • α = 1.0: Standard sharpening, good balance of enhancement and naturalness
  • α = 1.5-2.0: More pronounced sharpening, edges become more crisp
  • α = 3.0: Excessive sharpening, introduces artifacts and halos around edges
Evaluation with Blur-Sharpen Test:

I took a sharp image, blurred it, then attempted to sharpen it again. The results show that while sharpening can enhance perceived sharpnes, it cannot fully recover details lost during blurring. The process enhances edges but may also amplify noise and introduce artifacts.

Part 2.2: Hybrid Images

I created hybrid images that appear different when viewed from different distances by combining high-frequency content from one image with low-frequency content from another.

Technique

Hybrid images work by exploiting the fact that:

  • High frequencies dominate perception at close viewing distances
  • Low frequencies dominate at far viewing distances
  • By combining these strategically, we create images with dual interpretations
Interactive Hybrid Images: Use the sliders below each hybrid image to resize them and observe how the interpretation changes with viewing distance. Smaller images simulate viewing from far away (low frequencies dominate), while larger images simulate close viewing (high frequencies dominate).

Figure 3.42 Analysis:

This replication demonstrates the Laplacian pyramid blending technique from the seminal Burt and Adelson 1983 paper. Each row shows different frequency bands. The left column shows the apple Laplacian multiplied by the blending mask (showing where apple contributes), the middle column shows the orange Laplacian multiplied by (1-mask) (showing where orange contributes), and the right column shows the sum of these weighted contributions. This illustrates how each image contributes differently at different spatial locations and frequency bands. The bottom row shows the final reconstructed images, demonstrating perfect reconstruction from the Laplacian stacks.

Key Insights:
  • Gaussian stacks show progressive blurring, removing fine details at each level
  • Laplacian stacks isolate different frequency bands, with early levels capturing fine details and later levels capturing coarser features
  • The sum of all Laplacian stack levels reconstructs the original image perfectly
  • This multi-scale representation enables sophisticated blending techniques
  • Multi-resolution blending works by blending corresponding frequency bands separately, creating smooth transitions

Part 2.4: Multiresolution Blending

I implemented the Burt-Adelson multiresolution blending algorithm to seamlessly combine images using masks that are also processed through Gaussian stacks.

Algorithm Overview

  1. Create Laplacian stacks for both input images
  2. Create Gaussian stack for the blending mask
  3. Blend corresponding levels: blended[i] = mask[i] x image1[i] + (1 - mask[i]) × image2[i]
  4. Reconstruct final image by summing blended Laplacian levels

What I Learned

The most important thing I learned from this project is how frequency domain thinking fundamentally changes our approach to image processing. Rather than working directly with pixels, decomposing images into different frequency bands allows for much more sophisticated and intuitive operations.

Specifically, I learned the following:

  • Multi scale processing: How breaking images into frequency bands (through Gaussian/Laplacian stacks) enables operations that would be impossible in the spatial domain alone
  • Perceptual principles: How our visual system processes different frequencies differently, enabling techniques like hybrid images that exploit this to create images with distance-dependent interpretations
  • Smooth blending: How multi-resolution blending creates imperceptible transitions by handling each frequency band appropriately, something simple alpha blending cannot achieve
  • Convolution!: How this single mathematical operation underlies so many computer vision techniques, from basic edge detection to sophisticated image enhancement

This project demonstrated how understanding the mathematical foundations of image processing opens up a lot of creative possibilities that seem almost magical - like creating images that change based on viewing distance, or blending completely different scenes.
