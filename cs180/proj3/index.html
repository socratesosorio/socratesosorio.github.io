Part A.2: Recover Homographies

To align images, I computed homographies using point correspondences. A homography H is a 3×3 matrix that transforms points from one image to another: p' = Hp.

Implementation

I implemented the computeH(im1_pts, im2_pts) function that recovers the homography from point correspondences by solving an overdetermined linear system using least-squares:

def computeH(im1_pts, im2_pts): n = im1_pts.shape[0] # building matrix A in system Ah = b A = [] for i in range(n): x, y = im1_pts[i] x_prime, y_prime = im2_pts[i] # first equation (for x'): # h11*x + h12*y + h13 - h31*x*x' - h32*y*x' - x' = 0 # rearranged: h11*x + h12*y + h13 + 0 + 0 + 0 - h31*x*x' - h32*y*x' = x' A.append([x, y, 1, 0, 0, 0, -x*x_prime, -y*x_prime, x_prime]) # second equation (for y'): # h21*x + h22*y + h23 - h31*x*y' - h32*y*y' - y' = 0 A.append([0, 0, 0, x, y, 1, -x*y_prime, -y*y_prime, y_prime]) A = np.array(A) # system is Ah = 0 and h = [h11, h12, h13, h21, h22, h23, h31, h32, 1] # new form Ah = b A_coef = A[:, :-1] # first 8 columns b = A[:, -1] # last column # least squares h, residuals, rank, s = np.linalg.lstsq(A_coef, b, rcond=None) H = np.array([ [h[0], h[1], h[2]], [h[3], h[4], h[5]], [h[6], h[7], 1.0] ]) return H

I implemented image warping using inverse warping to avoid holes in the output. Two interpolation methods were implemented from scratch: nearest neighbor and bilinear interpolation.

Implementation

# Inverse Warping Algorithm: # 1. Compute output image dimensions by warping input corners # 2. For each pixel (x',y') in output image: # - Apply inverse homography: (x,y) = H^(-1) * (x',y') # - Interpolate value from input image at (x,y) # # Nearest Neighbor: Round (x,y) to nearest integer coordinates # Bilinear: Weighted average of 4 neighboring pixels

Part A.4: Blend Images into a Mosaic

I created panoramic mosaics by warping images to a common reference frame and blending them using distance-based weighted averaging to eliminate edge artifacts.

Blending Strategy

Instead of simple overwriting which creates harsh edges, I implemented alpha blending with distance-based masks:

# Distance-based Alpha Mask: # For each pixel, compute minimum distance to any edge (top/bottom/left/right) # y_dist = min(distance_to_top, distance_to_bottom) # x_dist = min(distance_to_left, distance_to_right) # alpha = min(y_dist, x_dist) / max_distance # - Alpha = 1.0 at image center # - Alpha = 0.0 at image edges # - Linear falloff in between # # Weighted Blending: # Final pixel = Σ(image_i * alpha_i) / Σ(alpha_i)
